# รายการแก้ไข 03 — v1.6.1

วันที่ 17 พฤศจิกายน 2026 แก้ตามภาพและรายการที่ผู้ใช้แจ้งหลังทดลองพรีวิว v1.6.0

| รายการ | พฤติกรรมหลังแก้ |
|---|---|
| หน้าแรกแสดงบทความไม่ครบ | ดึง 3 บทความที่เผยแพร่ล่าสุดจากทุกหมวดหมู่ เรียงตามวันเผยแพร่ หากวันตรงกันใช้บทความที่เพิ่มใหม่ก่อน ไม่ใช้ตัวกรองหมวดหน้าแรกเดิม และไม่ผูกกับจำนวนข่าวต่อหน้า |
| ไม่ต้องกรอกลิงก์บทความ | บทความใหม่ที่ไม่กรอก หรือกรอกเพียงช่องว่าง/ขีดกลาง จะได้ URL อัตโนมัติที่ไม่ซ้ำ ชื่อภาษาไทยล้วนที่แปลงเป็น URL ไม่ได้ใช้รหัสที่ระบบสร้างให้ |
| รักษาลิงก์เดิม | บทความเดิมที่เว้นช่องลิงก์ว่างจะเก็บ URL เดิม รวมลิงก์ที่ผู้ใช้สร้างไว้ก่อนอัปเดต ไม่เปลี่ยน URL ของบทความทั้งหมดอัตโนมัติ |
| แกลเลอรีภาพใหญ่และเรียงลงมา | ภาพย่ออยู่ในกรอบ 4:3 เรียง 3 ภาพต่อแถวบน Desktop, 2 บน Tablet และ 1 บน Mobile เพื่อไม่ให้ล้นจอ ปุ่มเรียงลำดับ/ลบอยู่กับภาพ คำอธิบายและเปลี่ยนภาพอยู่ในรายละเอียดแบบย่อ |

หน้าแรกแสดงเฉพาะบทความสถานะเผยแพร่ที่ถึงวันเผยแพร่แล้ว หากมีน้อยกว่า 3 จะแสดงเท่าที่มี ไม่เผยแพร่ฉบับร่างหรือบทความที่ตั้งเวลาในอนาคต

การดึงรายการล่าสุดใช้ `limit` แยกจากการตั้งค่าแบ่งหน้าข่าว ส่วนหน้าข่าวยังใช้ตัวกรองและจำนวนรายการต่อหน้าตามเดิม ไม่มี migration ใหม่ การตั้งค่าและข้อมูลเดิมยังอยู่

ไฟล์ ZIP พรีวิวที่ผู้ใช้แนบมีขนาดเกินขีดจำกัดนำเข้า 32 MiB จึงไม่ได้เปิดหรือทดสอบฐานข้อมูลเฉพาะในไฟล์นั้น ใช้ภาพประกอบ โค้ด v1.6.0 และข้อมูลชั่วคราวที่จำลอง 3 บทความต่างหมวดในการวิเคราะห์และทดสอบ ไม่ได้คัดลอกหรือเผยแพร่บัญชี/ข้อมูลส่วนตัวจากไฟล์แนบ

ก่อนอัปเดตให้หยุดพรีวิวเก่า เก็บสำเนาโฟลเดอร์เดิม แตก ZIP ใหม่ แล้วคัดลอก `.data` และ `.env` มายังโฟลเดอร์ใหม่ก่อนเปิด `START-WINDOWS.cmd` เพื่อใช้บทความ รูป และบัญชีเดิม หากกำหนด `DATA_DIR` ไว้ ให้คงโฟลเดอร์ข้อมูลตามค่านั้น
