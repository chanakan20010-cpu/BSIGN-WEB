# รายการแก้ไขรอบ 06 — v1.9.0

วันที่ 26 พฤศจิกายน 2026 ตามรายการที่ผู้ใช้อนุญาตให้แก้ไขในแชท

| คำขอ | ผลที่ปรับ |
|---|---|
| ไม่มีปุ่มลบไฟล์ภาพที่ไม่ต้องการ | คลังรูปภาพแสดงปุ่มลบ ชื่อไฟล์ หน้าต่างยืนยัน และรายการตำแหน่งที่อ้างอิง ปุ่มลบปิดเมื่อใช้งานอยู่ และตรวจซ้ำใน transaction เมื่อยืนยัน |
| ตัวอย่างก่อนบันทึกให้เหมือนหน้าเว็บจริง | ตัวอย่างใช้ public CSS, font faces และองค์ประกอบจริง ครบทั้ง 15 สไตล์ รวมปุ่มที่มีพื้นสี/ลูกศร เมนู แบรนด์ และข้อความบนพื้นเข้ม แยก CSS ของหลังบ้านออกจากตัวอย่าง |
| กำหนดสีพื้นหลังภาพโลโก้ | หน้าส่วนหัว/ส่วนท้ายเว็บไซต์มีสีพื้นหลังโลโก้ของตน เลือก HEX โปร่งใส หรือคืนค่า แสดงตัวอย่างจากองค์ประกอบเดียวกับหน้าเว็บ |
| จัดการข้อความให้คล้ายแถบเครื่องมือที่แนบ | แถบสไตล์ ฟอนต์ ขนาด ตัวหนา เอียง ขีดเส้นใต้ ขีดฆ่า สี ไฮไลต์ และจัดแนวอยู่ติดกับช่องข้อความ ตัวเลือกขั้นสูงพับได้ มีชื่อปุ่มและสถานะรองรับ keyboard |
| หลังบ้านทุกหน้าแบ่งข้อมูลชัดเจน | พื้นหัวข้อหลักสีครีม/เหลือง เลขส่วน หัวข้อกลุ่มและการ์ดย่อยน้ำหนักต่างกัน พร้อมแถบข้ามไปส่วนที่แก้ รองรับ Desktop/Mobile ตรวจทั้ง 19 หน้าทำงาน |

## วิธีใช้งาน

**ข้อความ:** เปิดหน้าจัดการของเนื้อหานั้น แล้วใช้แถบใต้ช่องข้อความ การจัดรูปแบบใช้ทั้งช่อง/ย่อหน้าและทั้ง TH/EN ร่วมกัน ข้อความยังเก็บเป็นข้อความธรรมดา ไม่รองรับการเลือกเฉพาะบางคำแล้วจัดรูปแบบต่างกัน เลือกฟอนต์ที่ติดตั้งในคลังเท่านั้น ขนาดเฉพาะช่องใช้ px เดียวทุกขนาดจอ; คืนค่าตามสไตล์เพื่อกลับไปใช้ขนาด responsive ของระบบ

ตัวอย่างรายช่องคงบริบทเดิม เช่น เมนูส่วนท้ายยังแสดงบนพื้นเข้ม แม้เลือกสไตล์ข้อความอื่น หน้า **สไตล์เว็บไซต์ → ตัวอักษร** เลือก TH/EN และ Desktop/Tablet/Mobile ได้ ตัวเลือกหน้าจอจำลอง breakpoint จริง ส่วนพื้นที่แสดงตัวอย่างจำกัดตามพื้นที่ของหลังบ้าน องค์ประกอบที่เปลี่ยนฟอนต์/สีใช้แบบร่างก่อนบันทึก

**ลบภาพ:** ที่คลังรูปภาพและไฟล์ ตรวจชื่อและสถานะก่อนกดลบ ยืนยันในหน้าต่างชื่อไฟล์ หากยังใช้งานให้แก้หรือเอาภาพออกจากเนื้อหาแล้วบันทึกก่อน ระบบนับทั้งข่าวเผยแพร่ ฉบับร่าง ข่าวตั้งเวลา และเอกสารหน้าต่าง ๆ การลบไฟล์ที่ไม่ถูกอ้างอิงเป็นการลบจากคลังและพื้นที่อัปโหลดจริง

**โลโก้:** ที่ส่วนหัวหรือส่วนท้ายเว็บไซต์ ใต้ภาพโลโก้เลือกสีพื้นหลัง หรือ “ไม่มีพื้นหลัง” การคืนค่าให้ส่วนหัวโปร่งใสและส่วนท้ายขาวตามดีไซน์เดิม สีนี้เป็นพื้นกรอบ/ภาพ ไม่เปลี่ยนพิกเซลพื้นสีที่ฝังในไฟล์ หากต้องการเห็นสีพื้นใหม่ควรใช้ PNG/WebP/SVG ที่โปร่งใส

## ข้อมูลและการอัปเดต

ไม่มี migration ใหม่ ไม่เปลี่ยนเนื้อหาหรือสไตล์ที่บันทึกไว้โดยอัตโนมัติ ฟิลด์รูปแบบข้อความและพื้นหลังภาพเป็นค่าเสริม การส่งข้อมูลจาก client เก่ารักษาค่าเดิมที่ไม่ได้ส่งมา รวมการสำรอง/กู้คืน ภาพที่ลบแล้วไม่มีการอ้างอิงจะตอบ HTTP 404

หยุดพรีวิวเก่าก่อนย้ายข้อมูล คัดลอก `.data` ทั้งโฟลเดอร์ (หรือ `DATA_DIR` เดิม) และ `.env` เดิมถ้ามีไปยังโฟลเดอร์รุ่นใหม่ก่อนเปิด START-WINDOWS ใช้บัญชีเดิม ZIP รุ่นนี้มีเพียง `.env.example` ไม่มี `.env` รหัสผ่านหรือฐานข้อมูลผู้ใช้รวมมา
