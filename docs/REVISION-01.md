# รายการแก้ไข 01 — v1.5.0

วันที่ 16 พฤศจิกายน 2026 อ้างอิงไฟล์ `รายการแก้ไขหน้าบ้าน  01.docx` และ `รายการแก้ไขหลังบ้สน 01.docx` ที่ผู้ใช้แนบ ข้อความและภาพประกอบในเอกสารใช้เป็นรายการแก้ไขตามคำขอรอบนี้ ผลทดสอบจริงและขอบเขตการตรวจอยู่ใน [VALIDATION.md](VALIDATION.md)

## หน้าบ้าน

| รายการในเอกสาร | สิ่งที่เปลี่ยนและจุดตรวจ |
|---|---|
| หน้าแรก: เพิ่มระยะห่างใต้รูปภาพและการ์ดข้อความให้เท่ากัน | ส่วนเปิดหน้า บริการ และจุดแข็งใช้ระยะบน/ล่างร่วมกัน ตรวจขอบล่างรูปและการ์ดก่อนเข้าส่วนถัดไปทั้ง Desktop/Tablet/Mobile |
| หน้าแรก/ข่าวสาร/เกี่ยวกับเรา/ติดต่อเรา: ลบพื้นหลังลูกศรในปุ่มสีเหลือง | ไอคอนลูกศรตำแหน่งเหล่านี้ใช้พื้นหลังโปร่งใสเป็นค่าเริ่มต้น ปุ่มยังใช้สีและลิงก์จริงตามการตั้งค่าของหน้า |
| ข่าวสาร: ลบพื้นหลังสีเหลืองอ่อนของไอคอนค้นหา | ไอคอนค้นหาใช้พื้นหลังโปร่งใสเป็นค่าเริ่มต้น ช่องค้นหาและตัวกรองยังอ่านข้อมูลข่าวจาก API |
| ข่าวสาร: ขยายภาพให้ชิดขอบล่างของเฟรม | ภาพข่าวเด่นเต็มความสูงกรอบและปรับตามคอลัมน์บนแต่ละขนาดจอ |
| ติดต่อเรา: ลบพื้นหลังไอคอนโซเชียลและใช้สีจริง | ค่าเริ่มต้น LINE เป็นเขียว, LinkedIn เป็นน้ำเงิน และ Facebook เป็นน้ำเงินของแพลตฟอร์ม พื้นหลังโปร่งใส ใช้ไอคอนที่มีแหล่งที่มาเดิมใน ASSETS.md |
| รายละเอียดข่าว: แสดงเนื้อหาทั้งหมดเมื่อคลิกการ์ด | ลิงก์การ์ดเปิด slug ของข่าวนั้น แสดงเนื้อหาที่บันทึกไว้ตามลำดับ รวมย่อหน้า ภาพในย่อหน้า และภาพเพิ่มเติม ไม่แสดงคำโปรยเดิมซ้ำเป็นเนื้อหา ดูข้อจำกัดต้นฉบับด้านล่าง |
| ทุกหน้าที่มีข่าว: ใช้รูปแบบเลย์เอาต์เดียวกัน | การ์ดข่าวในหน้าแรก หน้าข่าว และข่าวที่เกี่ยวข้องใช้ component เดียวกันสำหรับภาพ หมวด หัวข้อ คำโปรย และลิงก์อ่านต่อ ข่าวเด่นในหน้าข่าวยังเป็นส่วนเด่นตามดีไซน์ |

## หลังบ้าน

| รายการในเอกสาร | สิ่งที่เปลี่ยนและวิธีใช้ |
|---|---|
| เปลี่ยนไอคอนและสีได้ในหน้านั้น | เปิด **ข้อมูลเว็บไซต์** แล้วเลือกหน้าเว็บ ตำแหน่งไอคอนอยู่ในส่วนที่เกี่ยวข้อง เลือกไอคอน สีตัวไอคอน และสีพื้นหลัง/โปร่งใสจากตรงนั้น แล้วกดบันทึกด้านบน เอาหน้ารวมไอคอนออกจากการนำทาง |
| อัปโหลดจากอุปกรณ์แทนเลือกจากคลังทุกจุด | ช่องภาพ โลโก้ favicon และไฟล์ไอคอนมีช่องเลือกไฟล์จากอุปกรณ์โดยตรง ไม่มี dropdown เลือกจากคลังในช่องแทรกภาพ คลังรูปภาพและไฟล์ยังใช้ตรวจรายการ ที่มา และสิทธิ์ของไฟล์ที่อัปโหลดไว้ |
| หน้าภาพรวม: เปิด/ปิดเว็บไซต์เพื่อปรับปรุง | แก้หัวข้อและข้อความ TH/EN แล้วบันทึก หรือใช้ปุ่มปิดเว็บไซต์เพื่อปรับปรุง/เปิดเว็บไซต์ ผู้เยี่ยมชมเห็นข้อความที่บันทึกไว้ ขณะปิด API ข่าว ติดต่อ และสมัครข่าวสารตอบ 503 พร้อม Retry-After ระบบ login, /admin และการแก้ไขหลังบ้านยังใช้งานได้ |
| บทความ: เพิ่มย่อหน้าถัดไปและภาพในแต่ละย่อหน้า | กดเพิ่มย่อหน้า กรอกข้อความของภาษาที่เลือก อัปโหลดภาพประกอบได้ในย่อหน้านั้น เลือกภาพซ้าย/กึ่งกลาง/ขวา และอัตราส่วนเดิม, 16:9, 4:3, 1:1 หรือ 3:4 มีตัวอย่างก่อนบันทึก พร้อมย้ายลำดับหรือลบย่อหน้า |
| ภาพบทความ: เลือกหลายภาพจากเครื่องครั้งเดียว | ช่องภาพเพิ่มเติมของบทความรองรับการเลือกหลายไฟล์ในครั้งเดียว รวมได้สูงสุด 30 ภาพ แสดงความคืบหน้าและข้อผิดพลาด หากบางไฟล์สำเร็จแล้วจะเก็บภาพที่สำเร็จไว้ในแบบร่างให้ตรวจและบันทึก |
| หน้าแรก/เกี่ยวกับเรา/ข่าวสาร/ติดต่อเรา: เรียงทุกหัวข้อลงมาในหน้าเดียว | ภายในแต่ละแท็บหน้าเว็บ ทุกส่วนแสดงต่อกันตามลำดับเนื้อหา เลื่อนลงแก้ไขได้โดยไม่ต้องกดเลือกส่วนย่อยทีละส่วน แถบบันทึกและการสลับ TH/EN ยังใช้ร่วมกัน |

## ขอบเขตของการแก้ไอคอนและภาพ

ไอคอนที่เป็นตำแหน่งร่วมกันมีชื่อบอกไว้ เช่น ลูกศรการ์ดข่าวทุกหน้า และลูกศรแบนเนอร์ติดต่อ การแก้ตำแหน่งร่วมกันจะมีผลกับทุกหน้าที่ใช้ตำแหน่งนั้น ส่วนไอคอนของบริการหรือจุดแข็งแต่ละรายการเปลี่ยนเฉพาะตำแหน่งนั้นได้

SVG ที่อัปโหลดผ่านการ sanitize ฝั่ง server และแสดงด้วย image/mask ไม่แทรก markup ดิบลงหน้าเว็บ โหมด mask ใช้เปลี่ยนสีเดียวได้ ภาพ PNG/JPEG/WebP ใช้สีเดิมภายในภาพและเปลี่ยนได้เฉพาะพื้นหลัง ไม่อ้างว่าสามารถย้อมสีภายในไฟล์ raster ได้ ไอคอนของเบราว์เซอร์หรือบริการภายนอกอยู่นอกขอบเขตการตั้งค่า CMS

แต่ละภาพรับ SVG, PNG, JPEG หรือ WebP สูงสุด 8 MB และ 20 ล้านพิกเซล สามารถกรอกที่มาและสิทธิ์ก่อนอัปโหลดได้ เมื่อเลือกไฟล์และอัปโหลดเสร็จ ภาพจะถูกเก็บไว้ แต่การผูกภาพเข้าหน้าเว็บหรือบทความต้องกดบันทึกอีกครั้ง

## เนื้อหาข่าวที่มีต้นฉบับไม่ครบ

บทความเปิดตัวบริษัทมีเนื้อหาเต็มจาก Markdown ต้นฉบับ รวมข้อความเกริ่น เนื้อหา ภาพในเนื้อหา และภาพบรรยากาศ อีกสามข่าวเดิม ได้แก่ Cloud Architecture, เปิดรับพันธมิตร และ Cybersecurity มีเพียงหัวข้อ/คำโปรยจากไฟล์ต้นฉบับ ไม่มีเนื้อหาฉบับเต็มที่แนบมา

รุ่นนี้แก้ให้แสดงข้อมูลที่บันทึกไว้ทั้งหมดและไม่แสดงคำโปรยซ้ำ โดยรักษาข่าวเดิมไว้ ไม่แต่งเหตุการณ์หรือรายละเอียดบริษัทเพิ่มจากข้อมูลที่ไม่มี เจ้าของเนื้อหาสามารถเปิดข่าวนั้นในหลังบ้านและเพิ่มย่อหน้าฉบับเต็มพร้อมภาพได้ หากต้องการให้สามข่าวเดิมมีฉบับเต็มตามต้นฉบับ ต้องใช้เนื้อหาจากเจ้าของข่าวเพิ่มเติม

## ข้อความที่ยังต้องยืนยัน

บรรทัดสุดท้ายในไฟล์หลังบ้านเขียนว่า **“แก้ไขให้รายจัด”** และไม่มีรายละเอียดต่อท้าย จึงยังไม่ตีความเป็นข้อกำหนดใหม่ เพื่อไม่เปลี่ยนระบบผิดจากความต้องการ ส่วนนี้รอคำอธิบายเพิ่มเติมจากผู้ใช้

## อัปเดตและเปิดพรีวิว

1. หยุดพรีวิวเวอร์ชันเก่าและเก็บสำเนาโฟลเดอร์เดิมไว้
2. แตก ZIP v1.5.0 ลงอีกโฟลเดอร์ คัดลอก **.data** และ **.env** ไปโฟลเดอร์ใหม่ก่อนเปิดครั้งแรก หากตั้ง DATA_DIR เองให้รักษาโฟลเดอร์นั้นด้วย
3. ดับเบิลคลิก **START-WINDOWS.cmd** รอเว็บไซต์เปิดเอง แล้วเติม **/admin** เพื่อเข้าหลังบ้าน
4. ใช้บัญชีเดิมเมื่อย้ายข้อมูลมาด้วย เครื่องใหม่ที่ยังไม่มีบัญชีจะสร้าง Username/Password ใน **.data/initial-admin.txt** ตามขั้นตอนเดิม ไม่มีรหัสผ่านฝังมาใน ZIP

Migration รุ่น 2 ทำครั้งเดียวและปรับพื้นหลัง/สีไอคอนที่ระบุเฉพาะเมื่อยังตรงกับค่าเริ่มต้นเดิม หากผู้ใช้ตั้งไอคอนหรือสีไว้แล้ว ระบบจะคงค่าที่ตั้งไว้ สามารถแก้เป็นโปร่งใสจากช่องไอคอนในหน้านั้นได้ การเพิ่มการตั้งค่าปิดปรับปรุงและเนื้อหาแบบย่อหน้าไม่ล้างบทความเดิม และการบันทึกจาก client เก่าที่ไม่ส่งข้อมูลย่อหน้าใหม่จะไม่ลบข้อมูลใหม่เหล่านั้น

สถานะปิดปรับปรุง เนื้อหา รูป ไอคอน และบัญชียังอยู่หลัง restart และรวมอยู่ในข้อมูลสำรองตามระบบเดิม เก็บไฟล์สำรองในที่จำกัดสิทธิ์ คู่มือและผลทดสอบอยู่ใน [README](../README.md) และ [VALIDATION.md](VALIDATION.md)
