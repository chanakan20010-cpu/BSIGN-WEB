# รายการแก้ไข 02 — v1.7.0

อ้างอิงไฟล์ “รายการแก้ไข 02.docx” ที่ผู้ใช้แนบ และคำขอในแชทให้เอากรอบหัวข้อติดต่อออก/จัดกึ่งกลาง รายการในเอกสารถูกใช้เป็นข้อกำหนดของเว็บไซต์

| คำขอ | สิ่งที่ทำและจุดใช้งาน |
|---|---|
| ฟอนต์ไทย 20 แบบและเพิ่มเอง | สไตล์เว็บไซต์ → ตัวอักษร/คลังฟอนต์; ครบ IBM Plex Sans Thai, Noto Sans Thai, Sarabun, Anuphan, Prompt, Kanit, Bai Jamjuree, Chakra Petch, Krub, K2D, Athiti, Mitr, Noto Serif Thai, Pridi, Maitree, Taviraj, Trirong, Chonburi, Mali, Itim พร้อมไฟล์และใบอนุญาตท้องถิ่น |
| อัปโหลดฟอนต์ | WOFF2/WOFF/TTF/OTF; ตรวจโครงสร้าง/ขนาดและชื่อภายในฝั่งเซิร์ฟเวอร์ เลือกใช้กับสไตล์ ตัวอย่างก่อนบันทึก ป้องกันลบเมื่อใช้อยู่ และรวมไฟล์ใน backup/restore |
| แบรนด์ในแถบหลังบ้านตามภาพ | ใช้โลโก้ ชื่อแบรนด์ และบริษัทที่บันทึกในข้อมูลเว็บไซต์จริง ไม่ใช้ตัว B/ชื่อที่ฝังใน component |
| เปลี่ยนสีกรอบ/พื้นที่ข้อความจุดเด่น | หน้าแรก → การ์ดจุดเด่น → สีพื้น/สีกรอบรายใบ พร้อม preview และคืนค่าเฉพาะใบ ใช้ inset shadow จึงไม่เปลี่ยนขนาดการ์ด |
| จัดหน้าติดต่อหลังบ้าน | แยกหัวข้อหน้า ข้อมูลติดต่อ โซเชียล แบบฟอร์ม/ข้อความตอบกลับ และสำนักงาน/แผนที่ พร้อมไอคอนอยู่ในกรอบข้อมูลของรายการนั้น |
| เพิ่มโซเชียลและไอคอน | ครบ 20 แพลตฟอร์มตามไฟล์ มีที่มา/ใบอนุญาต เลือกชื่อบัญชี ลิงก์ สีและไอคอนในแต่ละรายการได้ ลำดับไอคอนย้ายตามข้อมูล |
| แบบฟอร์มและสถานะ | แยกชื่อช่อง/ข้อความตัวอย่างตามช่องกรอก ข้อตกลง ปุ่ม และข้อความสถานะเป็นกลุ่ม แก้ TH/EN และส่งเข้ากล่องข้อความจริง |
| จัดการหน้า Login | เมนูหน้าเข้าสู่ระบบ แก้ข้อความที่แสดงทุกกลุ่มและดูตัวอย่าง โดยบัญชี/รหัสผ่านยังใช้ระบบเดิมและไม่อยู่ในเอกสารแสดงผลสาธารณะ |
| หัวข้อหน้าติดต่อ | เอาเส้นกรอบออก จัดหัวข้อสามส่วนกึ่งกลาง หัวข้อสองส่วนหลักใช้สไตล์กลาง 24/22/20px ปรับต่อได้จากหลังบ้าน |

โซเชียลที่เพิ่ม: Facebook, Instagram, TikTok, YouTube, LINE, X, Threads, LinkedIn, Pinterest, Snapchat, Reddit, Discord, Telegram, WhatsApp, Bluesky, WeChat, Weibo, Douyin, Kuaishou, Xiaohongshu ข้อความ wearesocial.com และ learn.meltwater.com ในไฟล์เป็นแหล่งอ้างอิง ไม่ใช่ชื่อแพลตฟอร์ม

การอัปเดตเติมข้อมูลที่ขาดด้วย migration 4–5 รักษาข้อความ สไตล์ รูป ไอคอน บัญชี และข้อมูลใหม่เมื่อ client รุ่นเก่าบันทึกบางส่วน ไม่แตะ `.env` และไม่รวมรหัสผ่านเริ่มต้นใน ZIP
