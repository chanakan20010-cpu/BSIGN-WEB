# รายการแก้ไข 02 — v1.6.0

วันที่ 17 พฤศจิกายน 2026 อ้างอิงรายการและภาพที่ผู้ใช้รวบรวมในแชท แล้วแจ้งว่า **“แก้ไขได้”** รายการนี้ครอบคลุมการจัดการบทความ ข้อความ ไอคอน เลย์เอาต์หลังบ้าน และ Header/Footer ผลทดสอบจริงและขอบเขตการตรวจแยกไว้ใน [VALIDATION.md](VALIDATION.md)

## ตัวจัดการข่าวสารและบทความ

แบบฟอร์มเรียงเนื้อหาเป็น 3 ส่วนที่มองเห็นต่อเนื่อง มีลิงก์ข้ามไปยังแต่ละส่วน:

1. **ข้อมูลบทความ** — ชื่อบทความ คำโปรย และภาพปก
2. **เนื้อหาบทความ** — ย่อหน้าและภาพประกอบของแต่ละย่อหน้า
3. **แกลเลอรีภาพ** — ภาพบรรยากาศหรือภาพเพิ่มเติมที่เลือกหลายไฟล์จากอุปกรณ์ได้

URL หมวดหมู่ สถานะ และวันเวลาเผยแพร่อยู่ในแผงตั้งค่าการเผยแพร่ การเพิ่ม แก้ไข ลบ และเรียงย่อหน้าหรือภาพใช้ข้อมูลจริง บทความเดิมยังคงข้อความ ภาพประกอบ ภาพส่วนหัว และข้อมูลเพิ่มเติมไว้ การแปลงเนื้อหาเดิมเป็นย่อหน้ารักษารูปแบบข้อความและ metadata ที่บันทึกอยู่ด้วย

## รูปแบบและการจัดแนวข้อความ

เปิด **รูปแบบและการจัดแนวข้อความ** ใต้ช่องข้อความ แล้วเลือกจาก dropdown:

- **รูปแบบข้อความ** เลือกสไตล์กลาง เช่น หัวข้อหลัก หัวข้อส่วน หัวข้อรอง คำโปรย เนื้อหา และข้อความเน้น ชื่อเรียกตรงกับหน้าสไตล์เว็บไซต์ รวมสไตล์เฉพาะเมนู ปุ่ม และส่วนท้ายที่มีอยู่
- **การจัดแนวข้อความ** เลือกชิดซ้าย ชิดขวา กึ่งกลาง กระจายข้อความ หรือชิดขอบทั้งสองด้าน
- **ตามตำแหน่งเดิม** ใช้รูปแบบหรือแนวที่ตำแหน่งนั้นใช้อยู่ เหมาะกับข้อมูลเดิมที่ยังไม่ต้องการเปลี่ยน

**กระจายข้อความ** ขยายช่องไฟให้เต็มบรรทัดรวมถึงบรรทัดสุดท้าย ส่วน **ชิดขอบทั้งสองด้าน** จัดข้อความให้เต็มความกว้างบรรทัดและปล่อยบรรทัดสุดท้ายตามปกติ เป็นคนละตัวเลือกกับการจัดตำแหน่งภาพประกอบซ้าย/กึ่งกลาง/ขวา

การเลือกใช้สไตล์ไม่ได้สร้างชุดฟอนต์หรือขนาดเฉพาะจุด แต่ใช้ฟอนต์ สี น้ำหนัก ระยะตัวอักษร ระยะบรรทัด และขนาด Desktop/Tablet/Mobile จากสไตล์กลาง ข้อมูลรูปแบบเดียวกันใช้ร่วมกันทั้ง TH/EN มีตัวอย่างก่อนบันทึก สีหัวข้อที่กำหนดรายบรรทัดยังใช้ตามค่าของบรรทัดนั้น

## หน้าแรก เกี่ยวกับเรา และข่าวสาร

จัดเลย์เอาต์หลังบ้านเป็นกลุ่มที่มีหมายเลขตามลำดับเนื้อหา พร้อมระยะห่างและตัวควบคุมที่อยู่ใกล้ข้อมูลที่แก้ไข เลื่อนดูแต่ละส่วนต่อกันได้ ข้อความตั้งค่ารองใช้การเปิดดูเพิ่มเติมเพื่อลดความหนาแน่นของฟอร์ม

คำที่ใช้จัดหมวดในหลังบ้านแก้ได้ เช่น **บริการของเรา**, คำอธิบายใต้ชื่อส่วน, **แนะนำบริการ**, **จุดเด่น** และชื่อการ์ดแต่ละใบ:

- ชื่อส่วนและคำอธิบายใช้ระบุหมวดในพื้นที่จัดการ
- ชื่อช่องช่วยบอกว่ากำลังแก้ข้อมูลใด
- ชื่อการ์ดช่วยแยกรายการขณะเพิ่ม แก้ไข ลบ หรือจัดลำดับ

ชื่อที่ใช้ในหลังบ้านเหล่านี้แยกจากหัวข้อจริงบนเว็บไซต์ หากต้องการเปลี่ยนข้อความที่ผู้เยี่ยมชมเห็น ให้แก้ช่องเนื้อหา TH/EN ของส่วนนั้น แล้วกดบันทึกตามปกติ

## ไอคอนภายในการ์ด

การ์ดบริการ จุดเด่น พันธกิจ และคุณค่ามีตัวเลือกไอคอนอยู่ภายในการ์ดของตน สามารถเลือกไอคอน สีตัวไอคอน สีพื้นหลังหรือโปร่งใส และไฟล์จากอุปกรณ์ได้ ไอคอนที่บันทึกเป็นข้อมูลของการ์ดจะย้ายตามเมื่อเรียงการ์ด และไม่เปลี่ยนไอคอนของการ์ดอื่น

ตัวอย่างไอคอนจัดกึ่งกลางทั้งแนวนอนและแนวตั้งภายในกรอบ รวม SVG และภาพ raster โดยไม่ล้นออกนอกพื้นที่ ตัวควบคุมตำแหน่งที่ใช้ร่วมกัน เช่น เมนูมือถือหรือปุ่มแบนเนอร์ ยังระบุขอบเขตการเปลี่ยนแปลงไว้

SVG แบบ mask เปลี่ยนสีเดียวได้ ภาพ raster ใช้สีเดิมภายในไฟล์และเปลี่ยนได้เฉพาะพื้นหลัง การอัปโหลดใช้การตรวจไฟล์และ sanitize ฝั่ง server ตามระบบเดิม ไม่แทรก SVG ดิบที่ผู้ใช้อัปโหลดลง DOM

## หน้าจัดการส่วนหัวและส่วนท้าย

มีหน้าจัดการ **ส่วนหัวเว็บไซต์** และ **ส่วนท้ายเว็บไซต์** แยกกันอยู่ในข้อมูลเว็บไซต์:

- **ส่วนหัวเว็บไซต์** ดูแลโลโก้ ชื่อแบรนด์ เมนูนำทาง ภาษา และองค์ประกอบการนำทาง
- **ส่วนท้ายเว็บไซต์** ดูแลโลโก้ แบรนด์ เมนูส่วนท้าย ช่องทางติดต่อ และสำนักงาน

เมนูส่วนท้ายบันทึกแยกจากเมนูส่วนหัว จึงปรับลิงก์และลำดับได้อิสระ ส่วนข้อมูลแบรนด์ บริษัท และช่องทางติดต่อที่มีความหมายร่วมกันยังใช้ข้อมูลชุดเดียวกัน หน้าจัดการแยกกันโดยไม่ทำสำเนาข้อมูลบริษัทที่อาจขัดแย้งกัน อีเมลหลักคงเป็น **visit@bsign.work** ตามที่ผู้ใช้ยืนยันไว้ก่อนหน้า ภาพ Footer ใช้เป็นต้นแบบเลย์เอาต์

Footer ใช้พื้นดำ แบ่ง 4 คอลัมน์บน Desktop: โลโก้ในกรอบขาวพร้อมชื่อแบรนด์และบริษัท, เมนู, ช่องทางติดต่อ และสำนักงานใหญ่ ชื่อ BSIGN ใช้สีเหลืองและ TECH ใช้สีขาว หัวข้อและข้อความส่วนท้ายใช้สไตล์กลางสำหรับส่วนท้าย ปรับจำนวนคอลัมน์ตามหน้าจอ Tablet/Mobile

## อัปเดตโดยรักษาข้อมูลเดิม

1. หยุดพรีวิวเก่าและเก็บสำเนาโฟลเดอร์ไว้
2. แตก ZIP v1.6.0 ลงอีกโฟลเดอร์ แล้วคัดลอก **.data** และ **.env** จากโฟลเดอร์เดิมมาก่อนเปิดครั้งแรก หากกำหนด DATA_DIR ให้รักษาโฟลเดอร์ที่ใช้อยู่ด้วย
3. ดับเบิลคลิก **START-WINDOWS.cmd** รอให้เว็บไซต์เปิดเอง แล้วเติม **/admin** เพื่อเข้าหลังบ้าน
4. ใช้บัญชีเดิมเมื่อย้ายข้อมูลมาด้วย เครื่องใหม่ที่ยังไม่มีผู้ดูแลจะสร้าง Username/Password ใน **.data/initial-admin.txt** ไม่มีรหัสผ่านฝังมาใน ZIP

Migration รุ่น 3 ทำครั้งเดียว เก็บค่าของไอคอนเดิมไว้กับการ์ดที่ยังไม่มีไอคอนประจำตัว เพิ่มเมนูส่วนท้ายจากเมนูที่บันทึกอยู่เมื่อยังไม่มี และเติมสไตล์ส่วนท้ายที่ขาด ไม่เขียนทับค่าที่มีอยู่แล้ว รูปแบบข้อความ ชื่อในหลังบ้าน เนื้อหา รูป และบัญชีเดิมยังอยู่หลัง restart และรวมอยู่ในการสำรองตามระบบเดิม การบันทึกบางส่วนจาก client เก่าจะไม่ล้างข้อมูลรูปแบบหรือไอคอนใหม่ที่ไม่ได้ส่งมา
