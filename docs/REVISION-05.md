# รายการแก้ไขจากแชท — v1.8.0

ผู้ใช้รวบรวมรายการและอนุญาตด้วย “แก้ไขได้” วันที่ 23 พฤศจิกายน 2026

| คำขอ | ผลการปรับ |
|---|---|
| ชื่อหน้าปัจจุบันใน Footer เป็นตัวหนา | น้ำหนัก 700 เฉพาะหน้าปัจจุบัน รายการอื่น 400 คงกรอบและสีเดิม |
| เมนู Header ของหน้าที่เปิดอยู่หนากว่าปกติ | ใช้กฎเดียวกัน รวมเมนูมือถือและเมนูข่าวเมื่อเปิดรายละเอียดบทความ |
| ตัวกรองหมวดข่าวที่เลือกเป็นตัวหนา | 700 เฉพาะหมวดที่เลือก ที่เหลือ 400 และคงสีพื้นของสถานะที่เลือก |
| ปกข่าวเด่นจำกัดหัวข้อ/คำโปรย 3 บรรทัด | ทั้งสองส่วนย่อพร้อมจุดไข่ปลาในบรรทัดสุดท้าย ข้อมูลในระบบและรายละเอียดข่าวยังเต็ม ทั้ง TH/EN |
| ไอคอนหน้าติดต่อเท่ากัน | ข้อมูลติดต่อ โซเชียล และสำนักงานใช้กรอบ 40×40 และสัญลักษณ์ 22×22 px คงสี พื้นหลัง และไฟล์ที่ผู้ดูแลเลือก |
| เปลี่ยนสีข้อความจากหน้าจัดการของตัวเอง | เพิ่มสีรายช่องในรูปแบบข้อความ ใช้ Color Picker/HEX พร้อมตัวอย่างและคืนค่า ใช้ร่วมกัน TH/EN และไม่เปลี่ยนสไตล์กลางหรือช่องอื่น |

สีเฉพาะข้อความมีลำดับเหนือสีประจำสไตล์/สีหัวข้อรายบรรทัดเดิม เมื่อคืนค่าจะกลับไปใช้สีตามตำแหน่งนั้น ชื่อแบรนด์ใช้ช่องข้อมูลร่วมกันในส่วนหัว/ส่วนท้ายจึงแสดงสีเดียวกัน ไม่เพิ่ม migration และไม่แก้ `.data` หรือ `.env` ของผู้ใช้

ผลตรวจและขอบเขตการทดสอบอยู่ใน [VALIDATION.md](VALIDATION.md)
