เปิดพรีวิว BSIGN TECH v1.3.0

  1. ดาวน์โหลด ZIP แล้ว แตกไฟล์ทั้งโฟลเดอร์
  2. เปิดโฟลเดอร์ที่แตกออกมา ดับเบิลคลิก START-WINDOWS.cmd
    ถ้า Explorer ซ่อนนามสกุล จะเห็นชื่อ START-WINDOWS
  3. หน้าต่าง CMD จะเตรียมระบบอัตโนมัติ รอจนขึ้น Website ready แล้วเว็บไซต์จะเปิดในเบราว์เซอร์เอง ไม่ต้องพิมพ์คำสั่ง
  4. ต้องการเข้าหลังบ้าน เพิ่ม /admin ต่อท้าย URL เดิม หรือใช้ URL Admin panel ที่แสดงใน CMD
  5. เปิดโฟลเดอร์ .data แล้วเปิดไฟล์ initial-admin.txt ด้วย Notepad คัดลอก Username ไปกรอกช่องอีเมล และ Password ไปกรอกช่องรหัสผ่าน
    Explorer ที่ซ่อนนามสกุลจะแสดงชื่อไฟล์ initial-admin

เปิดหน้าต่าง CMD ค้างไว้ระหว่างพรีวิว เมื่อใช้งานเสร็จ กด Ctrl+C ในหน้าต่างนั้นเพื่อหยุด ข้อมูลยังอยู่เมื่อเปิดใหม่

ระบบสร้างบัญชีและรหัสผ่านสุ่มบนเครื่องคุณตอนเปิดครั้งแรกที่ยังไม่มีบัญชี ZIP ไม่มีรหัสผ่านฝังมา และ CMD แสดงเฉพาะตำแหน่งไฟล์ หากตั้ง DATA_DIR ใน .env ให้ดูตำแหน่งไฟล์จริงที่ CMD แสดง

เมื่อเปิดซ้ำจะใช้บัญชีเดิม หากเปลี่ยนรหัสผ่านแล้ว ให้ใช้รหัสผ่านใหม่ที่คุณตั้ง ค่าใน initial-admin เป็นรหัสเริ่มต้นและไม่เปลี่ยนตาม

อัปเดตจากเวอร์ชันเก่า

หยุดพรีวิวเก่า เก็บสำเนาโฟลเดอร์เก่าไว้ แล้วแตก ZIP ใหม่ในอีกโฟลเดอร์ คัดลอก .data และ .env จากโฟลเดอร์เดิมไปโฟลเดอร์ใหม่ ก่อนเปิดครั้งแรก เพื่อรักษาบัญชี เนื้อหา และรูปภาพ รวมไฟล์ initial-admin ถ้ามี หากกำหนด DATA_DIR เอง ให้รักษาโฟลเดอร์ข้อมูลนั้นด้วย

มีบัญชีเดิม แต่ไม่พบ initial-admin หรือจำรหัสไม่ได้

บัญชีที่ตั้งเองในรุ่นก่อนจะใช้รหัสเดิม ระบบไม่เขียนทับหรือตั้งใหม่อัตโนมัติ ถ้าจำไม่ได้ ให้หยุดพรีวิวแบบ CMD ก่อน แล้วเปิด OPEN-PREVIEW.vbs กด บัญชีแอดมิน / ลืมรหัสผ่าน เพื่อเลือกอีเมลและตั้งรหัสผ่านใหม่ ข้อมูลเว็บไซต์ยังอยู่

หากเปิดไม่ได้

รุ่นนี้ตรวจไฟล์แล้วปลดบล็อกเฉพาะสคริปต์ตัวเปิดของ BSIGN TECH อัตโนมัติ ไม่ต้องเปลี่ยน Execution Policy ของเครื่อง หากเครื่ององค์กรบังคับให้สคริปต์มีลายเซ็นหรือห้าม PowerShell ให้ฝ่ายไอทีอนุญาตตัวเปิดนี้

ถ้าเตรียมระบบไม่สำเร็จ อ่านข้อความใน CMD ตรวจอินเทอร์เน็ต และเปิดบันทึก .runtime/logs/setup.log ด้วย Notepad แล้วลองเปิด START-WINDOWS ใหม่

ใช้ Node.js portable ใน .runtime ไม่ต้องติดตั้ง Node.js เองหรือใช้สิทธิ์ Administrator ต้องใช้อินเทอร์เน็ตเตรียมครั้งแรก รองรับการดาวน์โหลดเครื่องมือสำหรับ Windows 64-bit (x64/ARM64) ดูผลทดสอบจริงใน docs/VALIDATION.md เก็บ .data และ .env ไว้เสมอเมื่ออัปเดต และเก็บไฟล์ initial-admin กับผู้ดูแลที่มีสิทธิ์เท่านั้น
