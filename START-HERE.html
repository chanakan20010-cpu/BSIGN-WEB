เปิดพรีวิว BSIGN TECH

  1. แตกไฟล์ ZIP ทั้งโฟลเดอร์ก่อน
  2. ดับเบิลคลิก OPEN-PREVIEW.vbs ในโฟลเดอร์นี้
    หรือดับเบิลคลิก START-WINDOWS.cmd ซึ่งเปิดหน้าต่างเดียวกัน
  3. รอเตรียมระบบครั้งแรก แล้วเว็บจะเปิดในเบราว์เซอร์อัตโนมัติ

ต้องการแก้ข้อความหรือรูป กด สร้างบัญชีแอดมิน ในหน้าต่างพรีวิว จากนั้นตั้งอีเมลและรหัสผ่านของคุณผ่านหน้าเว็บได้เลย

Username คืออีเมลที่คุณตั้งเอง ไม่มีรหัสผ่านสำเร็จรูป ตั้งรหัสผ่านอย่างน้อย 12 ตัวอักษร ถ้ามีบัญชีแล้วแต่จำไม่ได้ กด บัญชีแอดมิน / ลืมรหัสผ่าน ในหน้าต่างตัวเปิด เพื่อเลือกอีเมลและตั้งรหัสผ่านใหม่โดยข้อมูลเว็บยังอยู่

เมื่อใช้งานเสร็จ กด หยุดพรีวิวและปิด ข้อมูลจะยังอยู่เมื่อเปิดใหม่

อัปเดตจากเวอร์ชันเก่า

หยุดพรีวิวเก่า เก็บสำเนาโฟลเดอร์เก่าไว้ แล้วแตก ZIP ใหม่ในอีกโฟลเดอร์ คัดลอก .data และ .env จากโฟลเดอร์เดิมไปโฟลเดอร์ใหม่ก่อนเปิด เพื่อรักษาบัญชี เนื้อหา และรูปภาพ หากกำหนด DATA_DIR เอง ให้รักษาโฟลเดอร์นั้นด้วย

หากเปิดไม่ได้

ถ้า Windows แจ้งบล็อกไฟล์ที่ดาวน์โหลด: คลิกขวาไฟล์ ZIP → Properties → เลือก Unblock (ถ้ามี) → Apply แล้วแตก ZIP ใหม่ ไม่ต้องปิดโปรแกรมรักษาความปลอดภัยของเครื่อง หากเครื่ององค์กรไม่อนุญาตให้รันสคริปต์ ให้ฝ่ายไอทีอนุญาตตัวเปิดนี้

ถ้าหน้าต่างพรีวิวแจ้งเตรียมระบบไม่สำเร็จ ตรวจอินเทอร์เน็ตแล้วกด “ลองอีกครั้ง” หรือเปิดบันทึกจากลิงก์ในหน้าต่าง

รองรับ Windows 10/11 แบบ 64-bit (x64/ARM64) ใช้อินเทอร์เน็ตในการเตรียมครั้งแรก เครื่องมืออยู่ใน .runtime ไม่ต้องติดตั้ง Node.js เอง และไม่ต้องมีสิทธิ์ Administrator เก็บ .data และ .env ไว้เสมอเมื่ออัปเดตเวอร์ชัน
